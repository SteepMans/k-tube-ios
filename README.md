# K-Tube для iPhone

Клиент YouTube без рекламы для iPhone и iPad на SwiftUI и AVPlayer. Родственник K-Tube для компьютера
(форк [Stream Tube Desktop](https://github.com/Avaneesh-Inamdar/Stream-Tube-Desktop)): та же логика Innertube, те же
возможности, где их позволяет iOS.

Весь трафик к YouTube идёт через внешний прокси-шлюз по ключу пользователя: см.
[протокол шлюза](docs/gateway-protocol.md). Ключ вводится при первом запуске и хранится в Связке ключей.

## Возможности

- Главная: «Для вас» по истории, поиску и подпискам, «Новое» из подписок, популярное и категории.
- Поиск с подсказками, историей запросов и фильтрами (дата, тип, длительность, HD, 4K, HDR, субтитры, трансляции).
  Ссылка YouTube в поиске сразу открывает видео, канал или плейлист.
- Плеер: HLS до 4K, AV1 при аппаратном декодировании, выбор качества (отдельно для мобильной сети), скорость
  (в том числе своя для каждого канала), удержание для 2x, двойное касание для перемотки, полноэкранный режим,
  картинка в картинке, звук в фоне и на заблокированном экране, AirPlay, управление из Пункта управления.
- Главы, график популярных моментов, кадры при перемотке, продолжение с места остановки, повтор, очередь,
  автовоспроизведение следующего, режим «только звук», выбор звуковой дорожки (оригинал или перевод).
- Субтитры YouTube, включая автоматические, с настройкой размера, цвета и фона.
- SponsorBlock (пропуск, кнопка «Пропустить», отметки на шкале, главный момент), DeArrow (названия и обложки),
  Return YouTube Dislike.
- Описание с кликабельными таймкодами, комментарии (популярные и новые, ответы), чат трансляций, похожие видео,
  статистика для сисадминов, снимок кадра, ссылка с текущим временем.
- Shorts вертикальной лентой.
- Подписки без аккаунта Google: лента новых видео по RSS, фильтр по каналу, управление подписками.
- Библиотека: история (с поиском и паузой), «Смотреть позже», избранное, свои плейлисты, сохранённые плейлисты
  YouTube, загрузки для просмотра без сети.
- Скрытие Shorts, трансляций, просмотренного, комментариев, похожих и прочего; блокировка каналов и слов.
- Импорт подписок и истории: YouTube Takeout, NewPipe, FreeTube, OPML, CSV и резервная копия K-Tube для
  компьютера. Экспорт: резервная копия, NewPipe, OPML, CSV.
- Необязательный вход в аккаунт YouTube кодом на google.com/device (как на телевизоре, пароль в приложение не
  попадает): своя главная, плейлисты и история аккаунта, подписки и лайки уходят в аккаунт, сообщения в чат трансляций,
  перенос подписок, истории просмотров и поиска из аккаунта.
- Тема, акцентный цвет, язык и регион YouTube.

### Чего нет по сравнению с версией для компьютера

| Возможность | Почему |
|---|---|
| Загрузка через yt-dlp и FFmpeg, внешний плеер | на iOS нельзя запускать сторонние программы; загрузка сделана системным загрузчиком HLS |
| Вкладки, превью при наведении, горячие клавиши | нет мыши и окон; на iPad с клавиатурой работают системные сочетания |
| Юзерскрипт и ссылки `streamtube://` из браузера | Safari на iPhone не ставит юзерскрипты; ссылку YouTube можно вставить в поиск K-Tube или открыть через `ktube://open?url=…` |
| Масштаб интерфейса, цвет значка на панели задач, Wayland/X11 | на iOS это делает система (размер текста, тёмная тема) |
| Самообновление | обновления приходят через TestFlight |
| Отправка просмотров в историю YouTube через cookies браузера | на компьютере для этого берутся cookies входа из браузера; у приложения на iPhone нет доступа к cookies Safari. История аккаунта при этом подтягивается в K-Tube |
| Кодек VP9 и «улучшенный битрейт» | системный плеер iOS берёт HLS-потоки YouTube только в H.264 и AV1; VP9 и премиум-битрейт идут отдельными DASH-потоками, которые AVPlayer не играет |
| Настройка прокси (HTTP, SOCKS) и режим только IPv4 | весь трафик и так идёт через внешний шлюз |
| Театральный режим, плотность и число колонок | на телефоне это поворот в полноэкранный режим; сетка на iPad подстраивается сама |
| GIF, стикеры и эмодзи каналов в комментариях | пока показываются текстом (сделать можно, не успели в первую версию) |

## Сборка

Нужны Xcode 26 или новее и [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
xcodegen generate
open KTube.xcodeproj
```

Адрес шлюза в репозитории не хранится. Сборка берёт его из настройки `KTUBE_GATEWAY_URL`:

```sh
xcodebuild ... KTUBE_GATEWAY_URL=https://gateway.example
```

Без адреса приложение спросит его вместе с ключом.

Логика без интерфейса (`Core`) — это SwiftPM-пакет с тестами; он собирается и на Linux:

```sh
swift test --package-path Core
docker run --rm -v "$PWD:/src" -w /src swift:6.1-jammy swift test --package-path Core
KTUBE_LIVE=1 swift test --package-path Core --filter LiveTests   # проверки против живого YouTube
```

## CI

- `Core` — тесты на Linux при изменениях в `Core` и раз в неделю проверки против живого YouTube.
- `Simulator` — запускается вручную: сборка для симулятора и скриншоты экранов (артефакт `screens`).
  Отладочная сборка с `-ktubeDirect` ходит на YouTube напрямую и показывает демо-библиотеку.
- `TestFlight` — по тегу `vX.Y.Z`: тесты, подписанный архив и загрузка в TestFlight. Номер сборки — номер
  запуска workflow.

Секреты репозитория для TestFlight: `KTUBE_GATEWAY_URL`, `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8`,
`APPLE_DEV_CERT_P12`, `APPLE_DEV_CERT_PASSWORD`; переменная `APPLE_TEAM_ID`.

## Выпуск в TestFlight впервые

1. Bundle ID `ru.steepmans.ktube`: `python Tools/asc.py bundle` (или Certificates, Identifiers & Profiles →
   Identifiers → «+» → App IDs).
2. Запись приложения в App Store Connect (API этого не позволяет): Apps → «+» → New App → iOS, имя K-Tube,
   основной язык русский, Bundle ID `ru.steepmans.ktube`, SKU `ktube`, полный доступ.
3. Внутренняя группа тестировщиков с доступом ко всем сборкам: `python Tools/asc.py group "<название>"`
   (или TestFlight → Internal Testing → «+»), затем добавить в неё тестировщиков.
4. Секреты репозитория (см. выше), затем `git tag v0.1.0 && git push origin v0.1.0`.
